# Scanning Scope

## Authorized Use Only

This project is designed for safe and authorized network discovery.

Use this tool only on networks and systems where you have permission.

## Recommended Lab Targets

Safe examples:

- 127.0.0.1
- Local virtual machines
- Home lab systems
- Documentation IP ranges for examples

## Documentation IP Ranges

The repository uses documentation-safe IP ranges:

- 192.0.2.0/24
- 198.51.100.0/24
- 203.0.113.0/24

These ranges are used for examples and sample files.

## Not Included

This tool does not include:

- Exploitation
- Brute force
- Password attacks
- Vulnerability exploitation
- Evasion
- Aggressive scanning
