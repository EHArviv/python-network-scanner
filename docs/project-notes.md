# Project Notes

This project demonstrates basic authorized TCP network scanning using Python.

The tool checks whether selected TCP ports are open, closed, or filtered and generates structured reports for security review.

## Goals

- Practice Python socket programming
- Build a safe read-only security automation tool
- Generate security reports in multiple formats
- Demonstrate network security awareness
- Support Security Engineer portfolio workflows

## Safety

This tool is for authorized lab environments only.

Use it only on:

- Systems you own
- Localhost
- Lab machines
- Written authorized assessment scopes

Do not use it against public systems without permission.
